# Scientific name -> PubCRIS weed code
#
# Pl@ntNet returns a botanical name. PubCRIS uses common names, and only 15 of
# its aliases are proper binomials, so this file is the bridge. build-data.sh
# also auto-extracts binomials that PubCRIS embeds after a dash
# ("SOFT BROME - BROMUS MOLLIS"); entries here are the hand-checked ones and
# take priority.
#
# Format:  scientific name | PUBCRIS pest code
#
# One species may map to several codes. PubCRIS splits many weeds by growth
# stage or level of control ("SICKLE POD", "SICKLE POD - SEEDLING", "SICKLE POD
# - <9 LEAF STAGE"). List them all: the app unions the products behind them and
# shows which specific entry each product is registered against.
#
# Every code below was checked to exist in the current PubCRIS extract. If you
# add one, run build-data.sh and check the "crosswalk entries" count moves.
#
# Weighted to Central Queensland — what STEL actually gets called out to.
