# PubCRIS has 2502 "host" codes — far too many to put in a dropdown on a phone.
# This file collapses them into the handful of situations a spray contractor
# actually works in.
#
# Format:  id | Display name | POSIX extended regex matched against the host DESCRIPTION
#
# Every rule is tested against every host. A host can land in more than one group
# (PASTURE - RIGHTS OF WAY is genuinely both), which is correct — it means the
# product shows up under either heading. A host matching nothing falls to "other".
#
# Order sets the display order in the app, so the situations STEL actually sprays
# come first. Edit this file and re-run build-data.sh; no code changes needed.
